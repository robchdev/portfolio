Make a slow TCL TV fast again

Rendi di nuovo veloce la tua TV TCL

Budget TCL Android TVs have 2 GB of RAM and a pile of preinstalled extras that keep it full. This free script, run from your computer over Wi-Fi, switches them off, speeds up the menus and can swap the heavy Google home screen for a light one.

Le TV TCL Android economiche hanno 2 GB di RAM e tanti extra preinstallati che la tengono sempre piena. Questo script gratuito, lanciato dal computer via Wi-Fi, li spegne, rende i menu più rapidi e può sostituire la pesante Home di Google con una leggera.

  • Netflix, YouTube, HDMI, canali TV: non vengono toccati.

Five steps, about 15 minutes

Cinque passaggi, circa 15 minuti

You need a computer (Mac, Linux or Windows) on the same Wi-Fi as the TV, and the remote.

Ti servono un computer (Mac, Linux o Windows) sulla stessa Wi-Fi della TV, e il telecomando.

StepPasso

Install adb on your computer

Installa adb sul computer

adb is Google's free tool for talking to Android devices.

adb è lo strumento gratuito di Google per comunicare con i dispositivi Android.

  • Mac: with Homebrew:con Homebrew: brew install android-platform-tools
  • Linux: sudo apt install adb
  • Windows: install WSL, theninstalla WSL, poi sudo apt install adb
StepPasso

Turn on debugging on the TV

Attiva il debug sulla TV

  1. Settings › System › About: click Android TV OS build 7 times, until it says you are a developer.
  2. Impostazioni › Sistema › Info: premi 7 volte su Build del sistema operativo Android TV, finché dice che sei sviluppatore.
  3. Settings › System › Developer options: turn on USB debugging (and Network debugging, if listed).
  4. Impostazioni › Sistema › Opzioni sviluppatore: attiva Debug USB (e Debug di rete, se c'è).

On some models About is under Device Preferences.

Su alcuni modelli Info è in Preferenze dispositivo.

StepPasso

Find the TV's address

Trova l'indirizzo della TV

Settings › Network & Internet, select your Wi-Fi: the address looks like 192.168.1.50. TV and computer must be on the same network.

Impostazioni › Rete e Internet, scegli la tua Wi-Fi: l'indirizzo è tipo 192.168.1.50. TV e computer devono stare sulla stessa rete.

StepPasso

Download and do a test run

Scarica e fai una prova

In the Terminal, using your TV's address:

Nel Terminale, con l'indirizzo della tua TV:

curl -LO https://robchdev.github.io/portfolio/tools/tcl-tv-boost/tcl-tv-boost.sh
chmod +x tcl-tv-boost.sh
./tcl-tv-boost.sh 192.168.1.50 --dry-run

The TV asks Allow USB debugging?: tick Always allow and press OK. The test run lists what would change, without touching anything.

La TV chiede Consentire il debug USB?: spunta Consenti sempre e premi OK. La prova elenca cosa cambierebbe, senza toccare niente.

StepPasso

Apply, and restart the TV

Applica e riavvia la TV

./tcl-tv-boost.sh 192.168.1.50 --launcher

Type y to confirm. --launcher also installs the light home screen Projectivy Launcher (free, Play Store): the script opens its page on the TV, you install it with the remote and press Enter. If it doesn't become the home screen, the change is undone on its own. Leave out --launcher to keep the Google home.

Scrivi y per confermare. --launcher mette anche la Home leggera Projectivy Launcher (gratis, Play Store): lo script apre la sua pagina sulla TV, la installi col telecomando e premi Invio. Se non diventa la Home, la modifica si annulla da sola. Senza --launcher resta la Home di Google.

Changed your mind? ./tcl-tv-boost.sh 192.168.1.50 --restore puts everything back.

Ci hai ripensato? ./tcl-tv-boost.sh 192.168.1.50 --restore rimette tutto com'era.

FAQ

Domande frequenti

Can it break my TV?Può rompere la TV?

It doesn't uninstall anything or touch system files: it switches off apps and changes three settings, all restorable. Even without the backup, a factory reset brings everything back.

Non disinstalla niente e non tocca i file di sistema: spegne app e cambia tre impostazioni, tutto ripristinabile. Anche senza backup, un ripristino di fabbrica riporta tutto com'era.

Does it void the warranty?Fa decadere la garanzia?

It uses only the standard Developer options, no root and no unlocking. Still, use it at your own risk.

Usa solo le normali Opzioni sviluppatore, niente root e niente sblocchi. Resta comunque a tuo rischio.

Does it work on other brands?Funziona su altre marche?

It should be safe on any Android TV or Google TV and asks before going on, but the app list is made for TCL, so elsewhere it frees less.

Dovrebbe essere sicuro su qualsiasi Android TV o Google TV e chiede conferma prima di procedere, ma l'elenco delle app è fatto per TCL, quindi altrove libera meno.

A system update brought the apps back.Un aggiornamento ha riportato le app.

It can happen: run the script again.

Può succedere: rilancia lo script.

"cannot reach" errorErrore "cannot reach"

Check that the TV is on (not in standby) and on the same Wi-Fi, that USB debugging is on and that you accepted the prompt on the TV. Some models also need Network debugging.

Controlla che la TV sia accesa (non in standby) e sulla stessa Wi-Fi, che il Debug USB sia attivo e che tu abbia accettato la richiesta sulla TV. Alcuni modelli vogliono anche il Debug di rete.
