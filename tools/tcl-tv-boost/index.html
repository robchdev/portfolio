Make a slow TCL TV fast again

Rendi di nuovo veloce una TV TCL lenta

Budget TCL Android TVs ship with 2 GB of RAM and a pile of preinstalled services that keep it full. This free script, run from your computer over Wi-Fi, switches them off, speeds up the menus and, if you want, swaps the heavy Google home screen for a lightweight one.

Le TV TCL Android economiche hanno 2 GB di RAM e un mucchio di servizi preinstallati che la tengono sempre piena. Questo script gratuito, lanciato dal computer via Wi-Fi, li spegne, rende i menu più rapidi e, se vuoi, sostituisce la pesante Home di Google con una leggera.

  • Nothing is uninstalled, no root. Apps are only disabled.
  • Non disinstalla niente, niente root. Le app vengono solo disattivate.
  • Full undo. Every change is saved to a backup first; one command puts the TV back exactly as it was.
  • Si annulla tutto. Ogni modifica viene prima salvata in un backup; un comando rimette la TV esattamente com'era.
  • Try before you touch. --dry-run shows every change without making any.
  • Prova prima di toccare. --dry-run mostra ogni modifica senza farne nessuna.

Beta. The same changes, applied by hand on a TCL with Android TV 11, took free RAM from about 335 MB to about 650 MB after a restart. The script itself is new and has been tested on a simulated TV, not yet on many real ones: start with --dry-run, and tell me how it went.

Beta. Le stesse modifiche, fatte a mano su una TCL con Android TV 11, hanno portato la RAM libera da circa 335 MB a circa 650 MB dopo il riavvio. Lo script invece è nuovo ed è stato provato su una TV simulata, non ancora su tante TV vere: parti con --dry-run e fammi sapere come è andata.

Step-by-step guide

Guida passo passo

1. Install adb on your computer

1. Installa adb sul computer

adb is Google's free tool to talk to Android devices.

adb è lo strumento gratuito di Google per comunicare con i dispositivi Android.

  • Mac: install Homebrew, then in Terminal:installa Homebrew, poi nel Terminale: brew install android-platform-tools
  • Linux: sudo apt install adb
  • Windows: install WSL (Ubuntu), then inside itinstalla WSL (Ubuntu), poi al suo interno sudo apt install adb

2. Turn on debugging on the TV

2. Attiva il debug sulla TV

  1. Open Settings › System › About and click Android TV OS build 7 times with the remote, until it says you are a developer.
  2. Apri Impostazioni › Sistema › Info e premi 7 volte su Build del sistema operativo Android TV con il telecomando, finché dice che sei sviluppatore.
  3. Go back to Settings › System › Developer options and turn on USB debugging. If you see Network debugging or ADB over network, turn it on too.
  4. Torna in Impostazioni › Sistema › Opzioni sviluppatore e attiva Debug USB. Se vedi Debug di rete o ADB in rete, attiva anche quello.

Menu names change slightly between models; on some TCLs, About is under Settings › Device Preferences.

I nomi dei menu cambiano un po' da modello a modello; su alcune TCL Info si trova in Impostazioni › Preferenze dispositivo.

3. Find the TV's IP address

3. Trova l'indirizzo IP della TV

Settings › Network & Internet, select your Wi-Fi: the address looks like 192.168.1.50. TV and computer must be on the same network.

Impostazioni › Rete e Internet, scegli la tua Wi-Fi: l'indirizzo è tipo 192.168.1.50. TV e computer devono essere sulla stessa rete.

4. Download and try it without changing anything

4. Scarica e prova senza cambiare niente

curl -LO https://robchdev.github.io/portfolio/tools/tcl-tv-boost/tcl-tv-boost.sh
chmod +x tcl-tv-boost.sh
./tcl-tv-boost.sh 192.168.1.50 --launcher --dry-run

The first time, the TV shows Allow USB debugging? Tick Always allow and confirm. Then you get the plan:

La prima volta la TV chiede Consentire il debug USB? Spunta Consenti sempre e conferma. Poi vedi il piano:

5. Apply

5. Applica

./tcl-tv-boost.sh 192.168.1.50              # apps and animations onlysolo app e animazioni
./tcl-tv-boost.sh 192.168.1.50 --launcher   # also the lightweight home screenanche la Home leggera

It shows the plan and asks Apply? [y/N]: type y. With --launcher, if Projectivy Launcher isn't installed the script opens its Play Store page on the TV: install it with the remote, then press Enter on the computer. The Google home is disabled only after Projectivy is confirmed as the new home screen; if it doesn't take over, the change is rolled back automatically.

Mostra il piano e chiede Apply? [y/N]: scrivi y. Con --launcher, se Projectivy Launcher non è installato lo script apre la sua pagina del Play Store sulla TV: installalo con il telecomando, poi premi Invio sul computer. La Home di Google viene disattivata solo dopo aver verificato che Projectivy sia la nuova Home; se non lo diventa, la modifica viene annullata da sola.

At the end it offers to restart the TV: say yes, the improvement shows fully after a restart.

Alla fine propone di riavviare la TV: rispondi sì, il miglioramento si vede del tutto dopo il riavvio.

6. Undo, whenever you want

6. Annulla, quando vuoi

./tcl-tv-boost.sh 192.168.1.50 --restore

Backups live in ~/.tcl-tv-boost/, one file per run. Keep that folder: it's what makes the undo exact.

I backup sono in ~/.tcl-tv-boost/, un file per esecuzione. Non cancellare quella cartella: è quella che rende il ripristino esatto.

FAQ

Domande frequenti

Can it break my TV?Può rompere la TV?

It doesn't uninstall anything or touch system files, it only disables apps and changes three settings, all restorable. Even without the backup, a factory reset brings everything back.

Non disinstalla niente e non tocca i file di sistema: disattiva app e cambia tre impostazioni, tutto ripristinabile. Anche senza backup, un ripristino di fabbrica riporta tutto com'era.

Does it void the warranty?Fa decadere la garanzia?

It uses only standard Developer options, no root and no unlocking. Still, use it at your own risk.

Usa solo le normali Opzioni sviluppatore, niente root e niente sblocchi. Resta comunque a tuo rischio.

Does it work on other brands?Funziona su altre marche?

It should be safe on any Android TV or Google TV and asks before going on, but the app list is made for TCL, so on other brands it frees less.

Dovrebbe essere sicuro su qualsiasi Android TV o Google TV e chiede conferma prima di procedere, ma l'elenco delle app è fatto per TCL, quindi su altre marche libera meno.

A system update brought the apps back.Un aggiornamento ha riportato le app.

It can happen: run the script again.

Può succedere: rilancia lo script.

"cannot reach" errorErrore "cannot reach"

Check the TV is on (not in standby), on the same Wi-Fi as the computer, that USB debugging is on and that you accepted the prompt on the TV. Some models need Network debugging too.

Controlla che la TV sia accesa (non in standby), sulla stessa Wi-Fi del computer, che il Debug USB sia attivo e che tu abbia accettato la richiesta sulla TV. Alcuni modelli vogliono anche il Debug di rete.
